# GeoFS-Foreflight-Connector
Connect between GeoFS and ForeFlight using Node.JS, the browser console, and an EFB that supports X-Plane.

## How to use
Download Node.js, run `foreflight.js` on your laptop, open GeoFS, open the console, paste the contents of `browser.js` into the console, open an EFB on another device (that device must be connected to the same wifi network as the GeoFS one), and set the GPS source to X-plane.

## How to shut down
Close GeoFS, then go to the Node.js terminal and press Ctrl+C.
